# model/ — 行人行为模型

步骤 ②③ 的产出放在这里。模型主张：**只用终点吸引力、行人间的排斥力和接触力，就能复现圆环对趾实验中的束状人流。**

三项力的选取是刻意的——先把课程要求的三项力单独放进来，看清它们能走多远，再决定补什么。墙壁力（场景无墙）、成组力、视野各向异性、随机扰动一律先不加。

## 控制方程

```
m_i dv_i/dt = m_i (v⁰ e_i − v_i) / τ                                    ← ① 终点的吸引力
              + Σ_j [ A exp((r_ij − d_ij)/B) + k·g(r_ij − d_ij) ] n_ij  ← ② 排斥力 + 接触力(法向)
              + Σ_j  κ·g(r_ij − d_ij) (Δv_ji · t_ij) t_ij                ← ③ 接触力(切向摩擦)
```

`g(x) = max(0, x)`，`r_ij = 2r` 为两人身体半径之和，`e_i` 指向对趾点，`n_ij` 由 j 指向 i，`t_ij` 为 n 逆时针转 90°。

模型只做 XY 平面的点质量动力学，不含朝向的独立自由度：朝向始终与速度同向。

## 各力项的作用与标定依据

### ① 终点的吸引力

`m_i (v⁰ e_i − v_i) / τ` 把速度以时间常数 τ 松弛到"速率 v⁰、方向指向目标"。这是唯一让人前进的力，因此它决定了实验的时间尺度。

- τ = 0.5 s，取 Helbing 原始值。
- v⁰ = 2.0 m/s，**按本数据标定**：实测行进段速率的中位为 1.70 m/s，但在 2 m 内没有邻居时中位为 2.02 m/s。后者才是"不受干扰时想走多快"，所以用 2.0 m/s 作为期望速度。

### ② 行人间的排斥力

`A exp((r_ij − d_ij)/B)` 是指数衰减的软排斥，在身体还没接触（d_ij > 0.5 m）时就已经起作用，负责"提前避让"。这是产生避让行为的核心机制。

- A = 2000 N、B = 0.08 m，取 Helbing 原始值。
- 超过 3.0 m 截断，纯为省算力（该项在此距离下已衰减到可以忽略）。

这一项**没有方向性**：不管邻居在前面还是后面，排斥力大小相同。这是第 ③ 步失效的直接来源，见下。

### ③ 接触力

只在身体相互挤压（d_ij < 2r）时出现，分法向弹性力与切向摩擦两部分。

- k = 1.2×10⁵ kg/s²，κ = 2.4×10⁵ kg/(m·s)，取 Helbing 2000 的原始值。
- 这一项不是可选项：实测轨迹里全场最近两人间距的中位值约 0.4 m（小于 2r = 0.5 m），最小值只有 0.16 m，62.6% 的时刻存在身体接触。没有接触力，这些帧无法自洽。

## 积分

显式欧拉，内部步长 dt = 2 ms，再按 25 fps 重采样以与实测对齐。

步长的选取有约束：身体挤压的固有频率约 sqrt(k/m) ≈ 39 rad/s（周期 0.16 s），排斥力尺度 B = 0.08 m 对应的时间常数更短。2 ms 下 17 s 的仿真约 8500 步，单次运行数秒即可完成，稳定性也够（未观察到能量发散或穿透）。

## 结论：三项力能做什么、不能做什么

从实测初始条件出发仿真 25 s：

| 指标 | 实测 | 三力模型 |
|---|---|---|
| 中位到达时间 | 12.8 s | 17.8 s |
| 全部到达时间 | 17.0 s | 21.5 s |
| 中心区（<3 m）人数占比峰值 | 0.47 | 1.00 |
| 中心"挤满"（>80%）的时长 | 0 s | 7.0 s |
| 横向散布 IQR | 2.14 m | 1.76 m |
| 过中心 右 / 左 | 46 / 18 | 47 / 17 |
| 存在身体接触的时刻占比 | 62.6% | 2.7% |
| 最近两人间距 | 0.156 m | 0.446 m |

**成立的部分**：64 人全部到达，束状人流的形状、密度—速度的负相关趋势、过中心侧别分布都被复现了。

**失效的部分**：模型在圆心堆住约 7 秒；接触远少于真实；而"仅前方排斥"这一探针虽然消除了拥堵，却把侧别分布反转成 17/47。

详见 `../README.md` 的步骤 ③ 与 `results/fig8_sfm_failure.png`。加重排斥力或提高期望速度都只是缓解症状（A 从 500 提到 8000 N，拥堵只从 7.5 s 降到 2.4 s，且中位到达时间反而变长），因为拥堵的成因是"来自身后的排斥力把已经要进中心的人又推回中心"，属于机制缺陷而非参数问题。

## 下一步

补一个**方向性机制**，而不是继续调参：

1. 视野各向异性——排斥力按 `(λ + (1−λ)(1+cos φ)/2)` 加权，φ 为邻居相对自身朝向的夹角（Helbing 原文即有，本步刻意省略）。"仅前方排斥"的探针已经显示此项对拥堵极其敏感。
2. 侧向偏好——给期望方向加固定角度的右侧偏置，检验能否同时修好侧别与拥堵。
3. 可挤压的身体——0.25 m 的硬圆盘挡不住 0.16 m 的真实间距。
