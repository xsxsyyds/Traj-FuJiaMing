# 课堂任务：构建行人行为模型，复现圆环实验

> **目标**：提出一个行人行为模型，复现实验中的关键运动现象。
>
> **GitHub 提交结构**
>
> ```
> week02/
> ├── README.md      模型主张、依据、失效情形（完整版）
> ├── model/         行为模型本体、仿真、参数筛选
> └── results/       图表与动图
> ```

数据是课程提供的一次圆环对趾实验：六十余位行人均匀站在半径十米的圆周上，每个人要走到正对自己的另一侧。所有人的目标线都穿过圆心——走中心最短，但中心最挤，冲突从实验一开始就已经预定。帧率为每秒 25 帧，全程 17 秒。

## 任务 1 · 形成行为判断

> 可视化轨迹和速度变化，识别冲突、减速、转向与避让，并写出一至两条可以检验的行为判断。

把原始轨迹绕圆心旋转、让所有起点叠在一起之后，人流的形状看得最清楚：它是一条从一侧收缩、在圆心附近最窄、再向对侧张开的束。

![旋转对齐后的轨迹](results/fig2_trajectories_aligned.png)

这条"束"之所以看起来收拢，是因为左右两侧的人互相抵消，而不是因为每个人都在走直线。真正贴着中心线走完的只是一部分人，另一部分人则远远贴着外圈绕过去。避让的代价几乎全落在后者身上：最近圆心距离与迂回程度之间是单调的正相关。

速度方面，行人不是匀速走完这段路的。起步后逐步加速，行进中段达到峰值，临近目标时持续减速到站定；早到的人后半程确实站在原地等待，而不是边走边等。

![速度分析](results/fig4_speed.png)

更重要的是速率与拥挤程度的关系：周围人越多，走得越慢，孤立无人的时候明显更快。这说明行人确实会因为别人的存在而主动放慢，而不是各走各的。反映在时间上，先到与后到之间拉开了可观的差距。

![拥堵与到达](results/fig5_congestion.png)

方向方面，虽然全场平均下来并没有系统性的左偏或右偏，但**过中心时的侧别分布并不是对半开的**：以行进方向为参照，从右侧挤过去的人接近左侧的两倍半，这个偏斜在统计上极其显著，而且与每个人站在圆周上的起始位置几乎无关。

![方向分析](results/fig6_heading.png)

还有一件事与安全有关：全场最近两人间距的中位值已经小于两人身体半径之和，最小值处两人几乎贴在一起——真实数据里存在身体挤压，接触是这次实验里实际发生的事，而不是理论上的边界情形。

### 可以检验的行为判断

据此提出三条可以量化检验的判断，作为下一步建模的依据：

1. **两侧都走，但人数不对称**。两两对称的排斥力本身不含任何侧向偏好，因此这个不对称一定来自更上层的机制。
2. **避让的代价集中**。横向散开主要发生在接近中心之前，在中段达到最大、在两端收敛；绕行者的迂回程度与最近圆心距离正相关。
3. **速率受密度压制**。行人不是匀速走完这段路，而是"加速—巡航—减速"，并且会因周围人多而主动放慢。

## 任务 2 · 提出模型主张

> 明确行人使用哪些信息、如何作出判断，以及怎样更新速度或方向。允许借鉴或改造开源代码，也可以使用大模型辅助检索、解释与编程；提交时请说明来源、修改内容，以及你对关键机制的理解。

**模型主张**：只用三项力——终点的吸引力、行人间的排斥力、身体接触时的接触力——就足以让行人从圆环的一侧走到对趾点，并自然涌现出"中心最窄、两侧散开"的束状人流。

采用 Helbing 的社会力模型（1995 年的排斥力与终点吸引，2000 年的接触力与摩擦），控制方程为

```
m_i dv_i/dt = m_i (v⁰ e_i − v_i) / τ                                    ← ① 终点的吸引力
              + Σ_j [ A exp((r_ij − d_ij)/B) + k·g(r_ij − d_ij) ] n_ij  ← ② 排斥力 + ③ 接触力(法向)
              + Σ_j  κ·g(r_ij − d_ij) (Δv_ji · t_ij) t_ij                ← ③ 接触力(切向摩擦)
```

其中 `g(x) = max(0, x)`，`e_i` 指向对趾点，`r_ij = 2r` 为两人身体半径之和。

### 行人使用哪些信息

- **目标方向**：每个人知道自己起点关于圆心的对趾点在哪，并据此判断该往哪个方向走。
- **邻居的位置与速度**：排斥力只看两人中心距，接触力还用到相对速度的切向分量。行人据此判断"要不要让、让多少"。
- **自身当前速度**：通过松弛项调节加速与减速。

### 如何作出判断、怎样更新速度

判断被压缩成一个力：**先算出目标方向上的期望速度，再用排斥力与接触力去修正它**，最后按牛顿第二定律更新速度与位置。只有目标吸引力是主动的，另外两项都是被动的修正。三项力各有明确分工——吸引力决定"往哪走、走多快"，排斥力负责"提前避让"，接触力负责"挤在一起时怎么办"。

### 关键机制的理解

三项力的方向性差别是理解后面失效的关键：

- **终点吸引力是各向异性的**——它只指向目标，因此天然会把分散在圆周上的人往圆心收。
- **排斥力与接触力是各向同性的**——不管邻居在前面还是后面，推开的效果一样。这是模型缺口的来源。
- **接触力只在身体相互挤压时才出现**，是三项力里唯一带"硬约束"性质的：它保证人不会被压成一点。

三项力合起来的净效果是：人流被吸引向中心收拢，又在中心附近互相挤开，于是形成束状形态。这个宏观形态不需要额外规定。

### 参数

模型共 11 个可调量，命令行可逐个覆盖。真正决定行为的是四个：把速度拉向目标的快慢、想走多快、排斥力多强、排斥力管多远；其余是身体硬度与数值步长。

## 任务 3 · 实现与验证

> 从真实初始状态出发仿真。比较轨迹、速度和避让过程，检查模型能否稳定地产生合理行为，并报告失效情形。

仿真从**实测的初始位置**出发，目标取实测起点的对趾点。这样比较的是"同样的初始条件、同样的目标下，模型的行为与真人差在哪里"，而不是两次不同实验之间的统计量比较。

![模型与实测对比](results/fig7_sfm_vs_measured.png)

上排是旋转之前的世界系轨迹，下排是对齐后的形态。世界系这一排最能看清问题：实测的轨迹是一条条近乎笔直的弦，直接从圆周一端切到对侧；模型的轨迹却先绕着小圈打转、再卷向圆心，起手就在原地纠缠。**形状对了，走法不对。**

![失效分析](results/fig8_sfm_failure.png)

### 复现到什么程度

三项力确实把人送到了对侧，没有出现死锁或原地振荡；束状人流的形态被复现了；速率随密度下降的趋势方向也正确。

最完整被复现的是方向：过中心时的侧别分布几乎对上了实测，而且这个不对称在模型里是**由相互作用自然产生**的，并不需要显式规定。

### 失效情形

最醒目的失效是：**模型在圆心制造了一场持续数秒的全员拥堵**。

模型的行为序列是"先冲进中心、在中心堆住、然后才挤出去"。开始后不久，所有人都聚到圆心附近并几乎停滞；而实测的过程完全不同——没有人挤成一团，行人是一路散着走过去、陆续到达的。上面那张动图把这一点对比得最清楚：同一时刻，左边真人已经散开到四周，右边模型还挤在圆心不动。

接下来我按单因子扫描、双参数网格、区间细化三步调试参数，得到的结果比"调不好"更值得记录：

- **拥堵确实能压掉。** 把排斥力放大若干倍之后，中心拥堵基本消失，中位到达时间也明显向实测靠拢。看上去是成功的。
- **但代价是把接触力调没了。** 排斥力一大，人群就被撑开，两人再也不会靠近到身体接触的程度——而实测里大部分时间都有人贴着人走。于是这个模型最讽刺的一点出现了：**我点名要加进去的那一项力，在调好的配置里从头到尾一次都没真正起作用。**
- **而且人群变得太窄。** 想让人流散得更开，只能把排斥力的作用距离拉长；作用距离一拉长，又有人到不了目标。两件事互相拉扯。
- **打分最优其实落在不物理的参数上**——那组参数之所以分数最好，是因为它让所有行人都以超出实测上限的速度冲刺过去。这种"优化"没有意义。

还有一件独立的事：**身体不是硬圆盘**。实测里两人最近可以贴到远小于两个半径之和的距离，说明真实的人允许侧身擦过；而不变的硬圆盘会把这种擦过挡在外面。

最后是一个反例。如果让排斥力只来自前方——模拟"人看不到身后"——中心拥堵会彻底消失，到达时间和人群的散开宽度都比调参的结果更接近真实，接触也回来了。唯独一个指标崩了：**过中心的侧别分布完全反转**，与实测正好相反。

### 失效说明了什么

**拥堵的成因是"身后的人也在推我"**：已经要进入中心的人，被后面同样想挤进去的人推回来，于是谁也别想走。调大排斥力之所以能压掉拥堵，靠的其实是让人群提前散开、不再一起挤到圆心。

更关键的是方向：**拥堵、散开宽度、侧别这三件事被同一个自由度牵着走，而这个自由度是参数调不出来的。** 按下葫芦浮起瓢，说明三力模型缺的不是某个参数，而是一个**方向性的机制**——行人不是各向同性地互相推开，而是沿着一个共享的侧向约定分流。实测里"右侧通行者占绝对多数"这一点，正是那个缺失机制的痕迹：它把对撞的人流劈成两股，从而既避免了中心拥堵，又固定了侧别。

### 下一步

不在调参，而在补机制：

1. **视野各向异性**——让前面的邻居比后面的更重要，这正是社会力模型原文里就有、本次刻意省略的一项。
2. **侧向偏好**——给每人的期望方向加一个固定角度的偏置，检验能否在不牺牲侧别的前提下修好拥堵。
3. **可挤压的身体**——从固定半径的硬圆盘换成能够侧身擦过的形状。

## README 需要回答的三个问题

### ① 你的模型主张及其依据

**主张**：只用终点吸引力、行人排斥力和接触力三项力，就能让 64 位行人完成圆环对趾，并自然涌现束状人流。

**依据**：任务 1 的三条行为判断。其中"速率受密度压制"直接对应排斥力这一项；"避让的代价集中"对应横向散开的形态；"两侧都走但人数不对称"则给出了模型必然有缺口的前置证据——各向同性的排斥力不含方向信息，所以这一条注定复现不好。

### ② 使用的资料、开源代码与大模型

见任务 2 的"来源说明"表。要点：理论来自 Helbing 的两篇论文，**未使用任何开源仿真代码**，模型与积分器自行实现，只用本实验数据标定了期望速度与排斥力强度；大模型用于文献检索、参数释义与文字整理。

### ③ 哪些证据支持模型，模型何时失效

**支持**：64 人全部到达；束状人流形态；速率—密度负相关；过中心侧别分布几乎对上实测且是自然涌现的。

**失效**：中心拥堵（文献值参数下持续数秒，实测完全没有）；接触力在标定后彻底失效（接触率从实测的绝大多数时刻降到零）；横向散布比实测窄三成；期望速度或排斥力加得过头时有人到不了目标；"仅前方排斥"能修好拥堵却把侧别反转。
