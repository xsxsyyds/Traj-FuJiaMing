# week05 —— 三种经典跟驰模型的复现与对比

复现 OVM / FVDM / IDM，用上周（week04）的 NGSIM I-80 数据做三种场景的横向对比。

分析与结论见 [`作业.md`](作业.md)。

## 文件

| 文件 | 作用 |
|---|---|
| `car_following_models.py` | 三个模型的统一实现（净间距接口 + 弹道积分器） |
| `validate_models.py` | 四组复现自检（解析性质 / 线性稳定性 / 步长收敛 / 复现原文表 I） |
| `extract_ngsim_pairs.py` | 从 NGSIM 重建真实跟驰车对，含座标约定诊断 |
| `run_experiments.py` | 三个场景（前车匀速 / 前车减速 / 真实跟驰） |
| `plot_results.py` | 七张对比图，dpi = 300 PNG |
| `papers/` | 三篇原文 PDF |

## 复现参数（一律取原文值）

| 模型 | 参数 |
|---|---|
| OVM | κ = 0.85 1/s |
| FVDM | κ = 0.41 1/s，λ = 0.5 1/s |
| IDM | v0 = 33.3333 m/s，T = 1.6 s，a = 0.73 m/s²，b = 1.67 m/s²，δ = 4，s0 = 2 m，s1 = 0，l = 5 m |
| OV 函数（OVM/FVDM 共用） | V(s) = 6.75 + 7.91·tanh[0.13(s − 5) − 1.57]，s 为车头间距 |

Δ 符号口径：对外统一用**净间距**（前车车尾 → 本车车头）；OVM/FVDM 原文的 `s` 是车头间距，差一个 5 m 车长。

## 场景 C　真实跟驰（NGSIM I-80，205 对车）

| 模型 | 对数 | 位置 RMSE 中位 [m] | 均值 [m] | P90 [m] | 速度 RMSE 中位 [m/s] | 失败率 |
|---|---|---|---|---|---|---|
| 匀速基线 | 205 | 33.751 | 52.916 | 120.485 | — | 0.0% |
| OVM | 205 | 4.377 | 10.802 | 29.877 | 1.343 | 2.4%（5 对碰撞） |
| FVDM | 205 | **3.840** | 6.972 | 17.998 | 1.131 | 0.0% |
| IDM | 205 | 4.231 | **6.388** | **11.462** | **1.062** | 0.0% |

OVM 失败的 5 对全部落在低速段（平均车速 2.15–5.65 m/s）。
注：`位置 RMSE` 与 `净间距 RMSE` 在本实验里数学恒等（前车轨迹是同一份输入），不是两个独立指标。

## 数据

205 对车从 NGSIM I-80 自行重建（数据本身无 Preceding/Following 列），
按 (车道, 帧) 排序取相邻车；要求连续帧 ≥ 150 帧、速度 > 1 m/s、净间距 0.5–120 m，
再按速度分层抽样。候选 2,165 对 → 抽样 205 对（拥堵 <3 / 低速 3–6 / 中速 6–9 / 畅通 9+ 各 25/60/60/60）。
时长中位 31.5 s，平均净间距中位 12.18 m。

`local_y` 判定为**车头位置**（`gap_front` 负值占比 0.278%），故净间距 = `(y_lead − y_own) − L_lead`。
