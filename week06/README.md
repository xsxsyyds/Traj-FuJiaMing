# Week 06 — 统一社会力框架的人车混行

本周包含长廊迎面通行、宽度对比、失败与规则修正对照，以及直径 100 m 的混合圆环对趾实验。**圆环只指初始站位；主体穿过圆内到对面，不沿环道绕行。** 开放区域没有圆形硬墙，因而该场景的道路越界指标不适用。

## 模型选择与核实的来源

- Anvari, Bell, Sivakumar & Ochieng，*Modelling shared space users via rule-based social force model*，Transportation Research Part C **51 (2015), 83–103**，DOI: https://doi.org/10.1016/j.trc.2014.10.012 。线上发表信息含 2014，卷期年份为 2015。支持将社会力与规则结合用于共享空间；本代码是教学简化实现，不是论文逐式复现。
- https://github.com/felixlutz/carla-social-force-model ：README 明确是行人 SFM 与 CARLA 耦合，提供行人—动态车辆障碍作用及间隙接受规则。不能据此声称车辆也由同一个 SFM 控制。
- https://github.com/maprdhm/SPACiSS ：README 提供 AV 社会力控制选项，但同时明确其默认配置向目标前进、避墙而不避行人；是研究原型，不能直接当作本作业已验证的完整方案。
- ORCA/RVO 是可选的统一避碰框架，标准圆盘主体版本仍需扩展车辆矩形几何和运动学约束。社会力不是唯一可用方法，也没有证据证明本实现优于这些替代方案。

上述元数据及 GitHub README 于本次工作中在线核对。未复制外部项目代码。没有使用用户的 VDRP 毕设代码。

## 统一方程与规则

`a_i = (v_des,i - v_i)/tau_i + sum(f_ij)/m_i + f_wall,i/m_i`

社会排斥 `A_ij * w_ij * exp((r_i+r_j-d_ij)/B_ij)`；接触时叠加弹性与摩擦。车辆以沿纵轴分布的三个半径 0.9 m 圆盘近似计算力，**圆盘并集不覆盖矩形角部**。最终碰撞使用真实圆形/矩形几何而非圆盘近似；角部漏排斥可能导致碰撞，结果不能称为安全控制器。

| 参数 | 行人 | 车辆 |
|---|---:|---:|
| 碰撞尺寸 / m | 半径 0.25 | 长 4.5，宽 1.8 |
| 质量 / kg | 70 | 1500 |
| 期望速度 / (m/s) | 1.3 | 7.0 |
| 松弛时间 / s | 0.5 | 2.5 |
| 前向感知范围 / m | 14 | 45 |
| 减速净空 / m | 2.0 | 16.0 |
| 停车净空 / m | 0.15 | 3.5 |
| 最大加速度 / (m/s²) | 3 | 2 |
| 最大减速度 / (m/s²) | 5 | 6 |

完整常量以 `unified_sfm.py` 为准，类型参数另存 `results/parameters.json`。旧版遗留的 `t_safe` 字段当前未使用。

| 触发条件 | 动作 |
|---|---|
| 前向感知范围内主体的横向投影重叠 | 依据净空在停止与减速阈值之间线性缩小期望前进速度；前方让开则恢复 |
| 长廊侧移规则开启 | 行人回归道路右侧横向偏好，停车只抑制纵向速度，仍可侧移；车保持中心线纵向行驶 |
| 长廊侧移规则关闭 | 行人横向偏好回到中心线，用于规则失败对照；初始位置与启用规则时相同 |
| 开放区域预测未来 6 s 内最近接近距离不足 | 共用右侧避让形式；行人与车的最大侧向期望修正系数分别为 1.2 与 3.0 m/s |
| 车辆转向 | 禁止横向滑移，将侧向加速度转换为转向，转弯半径下限 5.2 m，角速度上限 0.6 rad/s |

车不是无约束的全向点；但这仍是简化运动学，不包含轮胎侧偏、转向执行器或真实驾驶标定。规则中的相互投影也是局部近似，未承诺连续时间避碰。

## 场景与固定设置

- 长廊长 60 m，6 名行人从左向右、1 辆车从右向左；行人纵向间距 2.4 m，种子 0，起始速度 0.4 m/s；车辆起点 x=57 m，起始速度 1 m/s。不同宽度保持中心线坐标下起点、人数、速度和参数相同，仅墙位置与同一规则计算出的横向偏好随宽度变化。
- 宽度依次为 5.0、3.5、2.2 m；另在相同 3.0 m 场景中关闭/启用侧移规则对照。车固定沿中心线，3.0 m 时每侧仅剩 0.6 m；虽然能放下直径 0.5 m 的行人，但安全余量很小。2.2 m 小于车宽与行人直径之和，即使横向重新分配也无法并排通过。
- 对趾：20 个主体等角度排列于半径 50 m 圆周，行人与车交替，各 10 个，初始速度为零、车辆朝向目标，目标为初始点的负值。到目标距离小于 1.2 m 即退出场景。长廊则要求身体纵向范围完全跨出出口。
- 积分步长与检查间隔均 0.01 s；最长 150 s，全部到达时提前结束。采用半隐式欧拉位置更新，不做硬投影、位置回退或事后消除碰撞。
- 固定参数单次运行，没有标定、网格搜索、多种子稳健性实验或步长收敛证明。所有时间和通过率均仅针对这里的明确设置。

## 实测结果

| 场景 | 行人到达 | 车辆到达 | 全部到达用时 / s | 碰撞步数 | 最大越界 / m |
|---|---:|---:|---:|---:|---:|
| 宽长廊（5 m） | 6/6 | 1/1 | 47.66 | 0 | 0.0000 |
| 窄长廊（3.5 m） | 6/6 | 1/1 | 47.82 | 0 | 0.0000 |
| 空间不足（2.2 m） | 0/6 | 0/1 | 未全部到达 | 0 | 0.0000 |
| 关闭侧移规则（3 m） | 0/6 | 0/1 | 未全部到达 | 0 | 0.0000 |
| 启用侧移规则（3 m） | 1/6 | 0/1 | 未全部到达 | 29 | 0.0037 |
| 人车混合圆环对趾 | 0/10 | 0/10 | 未全部到达 | 0 | 0.0000 |

3.0 m 的规则修改**没有成功修复**：只到达一名行人，并出现 29 个碰撞时间步与最大约 0.0037 m 越界。圆环对趾没有碰撞，但全部主体未到达，属于僵持失败。按用户要求直接保留固定参数结果，不继续调参。

碰撞计数排除已经退出的主体。圆—矩形采用矩形局部坐标下的有符号距离；车—车用分离轴定理。`min_clearance` 对车—车是 SAT 有符号轴间隙，不是欧氏净距，不能跨几何类型直接比较。步数是采样统计而非独立事故数；有限步长没有碰撞不构成连续时间安全证明。`t_all_arrived` 在未全部完成时为空，避免把最后一个已到达者的时间误当全部完成时间。

```powershell
python -m pip install -r requirements.txt
python validate_model.py
python run_all.py
python plot_results.py
```
